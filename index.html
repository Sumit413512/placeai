Security model

Role selection is verified by the backend.

Student, Recruiter, Institution Admin and Platform Admin are separate authorization domains. Selecting a role in the interface does not grant that role.

Role verification

The selected workspace must match the authenticated account role.

Tenant boundaries

Institution data remains organization-scoped in backend queries and authorization.

Session security

Refresh sessions are rotated and can be revoked.

Production persistence

Production records and uploaded files persist in PostgreSQL-backed storage.
