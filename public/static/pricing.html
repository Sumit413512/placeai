For independent students using PlaceAI preparation features. The application currently applies a 3-day preparation trial before a paid subscription is required for continued premium access. University-linked students use institution-sponsored access instead of this individual subscription.

AI Career Roadmap — ₹20 one time

A one-time feature unlock for eligible independent students. The Career Roadmap is not included in the free trial. It is available through paid-plan access or an explicit one-time entitlement according to the production access rules.

University and institutional access

Institutional packages are provided through an authorized PlaceAI access and commercial process rather than the independent-student checkout. Institutions can use Request access to start that process.
